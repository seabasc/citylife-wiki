# Storage Units

Secure personal storage units across San Andreas! Store your items safely with character-specific locking and multiple tiers available.

### Storage Tiers & Capacity

| Tier            | Slots    | Weight Capacity | Access                                                                    |
| --------------- | -------- | --------------- | ------------------------------------------------------------------------- |
| Tier 1          | 30 slots | 600lbs          | Purchase via Tebex |
| Tier 2          | 60 slots | 1,200lbs        | Purchase via Tebex |
| Tier 3          | 90 slots | 2,000lbs        | Purchase via Tebex |
| Platinum        | 40 slots | 1,000lbs        | Platinum Supporters                                                       |
| Content Creator | 50 slots | 1,000lbs        | Content Creators                                                          |

### Character Binding

> **Note:** :  Storage units are bound to the character that first accesses them (Can be unbound)!

#### First Time Access

* When you first access a storage unit, it will be bound to your current character
* A confirmation prompt will warn you before binding
* Once bound, only that character can access the storage
* Other characters on your account cannot access that storage unit

#### Binding Rules

*  Same character? Full access to your storage
*  Different character? Access denied
*  Unbound storage? Will bind to current character on first access<br>
