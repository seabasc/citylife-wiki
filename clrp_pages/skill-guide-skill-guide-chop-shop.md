# Chop Shop

Chop Shop is a skill that can be leveled by Chopping Cars! Below is your Chop Shop Skill cheat-sheet.

## Unlockable

* [x] Reaching Level 15 Unlocks Muscle Cars
* [x] Reaching Level 25 Unlocks Sports Cars
* [x] Reaching Level 50 Unlocks Super Cars
* [x] Reaching Level 65 Unlocks Hyper Cars

## Reward Boosts

* [x] The better the category, the better the rewards!
