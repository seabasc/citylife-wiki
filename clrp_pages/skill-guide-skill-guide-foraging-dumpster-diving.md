# Dumpster Diving

Dumpster Diving is a passive skill that can be leveled by Searching through Trash! Below is your Dumpster Diving cheat-sheet!

## Unlockable

* [x] You can search basic bins and bags right off the bat!
* [x] Reaching Level 25 allows you to search Large Dumpsters for better loot!
* [x] Reaching Level 50 allows you to search and Scrap Vehicles for even better loot!
* [x] Reaching Level 85 removes the searching mini-game entirely!&#x20;

## Reward Boosts

* [x] As you level up, your chance to receive the golden bottle also increases!
* [x] Reaching Level 15 Increases existing reward chances from normal bins and bags
* [x] Reaching Level 25 Increases existing reward chances from normal bins and bags
* [x] Reaching Level 35 Increases existing reward chances from all sources
* [x] Reaching Level 50 Increases existing reward chances from all sources
* [x] Reaching Level 65 Increases existing reward chances from all sources
* [x] Reaching Level 75 Increases existing reward chances from all sources
* [x] Reaching Level 100 unlocks new rewards for scrapping, and increases existing reward chances from all sources
