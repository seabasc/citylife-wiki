# Thieving

Thieving is a skill that can be leveled by you robbing houses! Below is your Thieving Skill cheat-sheet.

## Unlockable

* [x] At Level 0, start with Tier 1 Bank Trucks, Robbing Parking Meters, and Two Container Heists
* [x] Reaching Level 5 Unlocks Tier 1 Interiors, and a New Container Heist
* [x] Reaching Level 10 Unlocks Tier 2 Interiors, Tier 2 Bank Trucks, Robbing Mailboxes, ATM Drill Robberies
* [x] Reaching Level 15 Unlocks Tier 3 Interiors, a New Container Robbery, and ATM Rope Robberies
* [x] Reaching Level 20 Unlocks the Silent Route in the Bobcat Heist
* [x] Reaching Level 25 Unlocks Tier 1 Luxury Interiors, Robbing Large Blue Mailboxes, and a New Container Heist
* [x] Reaching Level 30 Unlocks Tier 3 Bank Trucks
* [x] Reaching Level 35 Unlocks Robbing House Packages
* [x] Reaching Level 45 Unlocks Tier 2 Luxury Interiors
* [x] Reaching Level 65 Unlocks Tier 3 Luxury Interiors
